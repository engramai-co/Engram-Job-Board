# Governance

Engram-Job-Board is an Engram-maintained open-source project. Repository administrators under [engramai-co](https://github.com/engramai-co) control access, merging, releases and security reporting.

## Decisions

Maintainers can approve ordinary fixes directly. Substantial features and breaking changes need a public issue explaining the motivation, alternatives and migration plan before implementation. Maintainers make the final decision based on user value, privacy, project scope and maintenance cost—not employer brand rankings or volume of applications.

Community contributions do not automatically grant repository access. Maintainer appointments and access changes require organization administrator approval. Adding a second active maintainer is desirable as the project grows; no additional person's participation is implied by this release.

## Maintenance

Issue triage, reviews, security response and releases are best effort. There is no guaranteed SLA or scheduled release cadence. The current `main` branch is the supported development line. Security-sensitive changes are handled privately before public disclosure.

Public issues and pull requests are the normal venue for technical decisions. Governance changes should be proposed in an issue and approved by repository maintainers. Conduct and security reports are exceptions to the public-discussion preference.
